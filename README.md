# 🎮 Simon Says Game

An interactive, web-based classic **Simon Says** memory game designed with modern UI, smooth animations, and touch support for both desktop and mobile screens.

## Features
- **Cross-Platform Playability**: Fully responsive layout supporting both Touch events (Mobile) and Mouse Clicks (Desktop).
- **High-Score Tracking**: Uses `LocalStorage` to save and display your highest score across sessions.
- **Dynamic Feedback**: Visual flashes and dynamic screen alerts on Game Over.
- **Modern UI**: Styled with modern Google Fonts, circular arcade button layouts, and smooth CSS transitions.

## How to Play
1. Click or Touch anywhere on the screen to start the game.
2. Watch the sequence of color flashes carefully.
3. Tap the buttons in the exact same order as shown.
4. With each successful round, the sequence gets longer and level increases!
5. One wrong tap will end the game and reset your sequence.

## Tech Stack
- **HTML5**: Game structure and semantic elements.
- **CSS3**: Modern 2x2 Grid layout, custom color palettes, glowing flash animations, and responsive breakpoints.
- **JavaScript (ES6+)**: DOM manipulation, event listeners, array handling, timers, and game logic.
